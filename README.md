# GreenGrid
GreenGrid: Sustainable Campus Simulator (SDG 12)
A web-based 2D game where students plan a virtual campus by placing
sustainable facilities within a budget and see their sustainability score.
SDG 12: Responsible Consumption and Production.

## Team

## How to run
Download index.html and open it in any browser.
